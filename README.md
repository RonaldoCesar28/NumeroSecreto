<h2> 📝 Resumo do Projeto </h2>

O Número Secreto é um jogo interativo desenvolvido em JavaScript, cujo objetivo é desafiar o usuário a descobrir um número gerado aleatoriamente pelo sistema. Além de proporcionar uma experiência divertida, o projeto explora conceitos fundamentais de lógica de programação, manipulação do DOM e interação com o usuário.

A cada nova partida, o computador gera um número secreto dentro de um intervalo previamente definido no código. O jogador realiza tentativas para descobrir esse número e recebe dicas após cada chute, tornando o jogo dinâmico e estimulando o raciocínio lógico.

<img src="NumeroSecreto.png" alt="Imagem do Número Secreto" width="100%">

<h2>🎯 Como o jogo funciona:</h2>

<h4>🔹 Geração do número secreto</h4>
<p>O sistema gera automaticamente um número aleatório.
O intervalo de valores é definido diretamente no código (por exemplo, de 1 a 50).</p>
<h4>🔹 Tentativas do jogador</h4>
<p>O usuário informa um número através da interface.
O sistema compara o valor digitado com o número secreto.</p>
<h4>🔹 Dicas durante o jogo</h4>

<p>Após cada tentativa, o jogo informa se:</p>

📈 O número secreto é maior que o chute informado, 📉 O número secreto é menor que o chute informado.
Essas dicas ajudam o jogador a encontrar o número correto utilizando lógica e eliminação de possibilidades.

<h4>🔹 Final da partida</h4>

<p>Quando o jogador acerta o número secreto:</p>

É exibida uma mensagem de sucesso.
O sistema informa quantas tentativas foram necessárias para encontrar o número correto.
O jogo pode ser reiniciado para iniciar uma nova partida com outro número aleatório.

<h2>🚀 Principais aprendizados com o projeto</h2>

<h4>Este projeto permitiu colocar em prática diversos conceitos essenciais para quem está iniciando no desenvolvimento web, entre eles:</h4>

Desenvolvimento da lógica de programação.
Criação de algoritmos para tomada de decisão.
Manipulação dinâmica de elementos da página.
Tratamento de entradas do usuário.
Organização do código em funções reutilizáveis.
Implementação de regras de negócio utilizando JavaScript.
